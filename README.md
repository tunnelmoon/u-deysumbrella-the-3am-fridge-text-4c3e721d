# The 3AM Fridge Text

make.fun bounty entry: the one line a smart fridge texts its owner at 3am.

> It's 3am. The kale is still here. The cake is gone. I am not a snitch, but I am a witness.

`main.ts` (Node 22, stdlib only) writes the line to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`, validating the 1-140 character gate and doing a round-trip read-back check.
